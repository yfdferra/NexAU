# 抽奖转盘大转盘应用

一个使用纯原生 HTML + CSS + JavaScript 实现的可交互抽奖转盘应用，无需依赖任何第三方框架、库或插件。

## 功能特性

### 🎡 基础功能
- 圆形抽奖转盘，具备清晰的扇形区块划分
- 每个扇形对应一个奖项，带有独立背景色
- 扇形内部显示清晰的奖项名称
- 平滑旋转动画（5秒左右），采用先快后慢的过渡效果
- 「开始抽奖」按钮，旋转过程中按钮禁用（防重复点击）
- 抽奖结果判定准确，根据转盘最终停止位置识别中奖奖项

### ⚙️ 配置弹窗
- 页面右上角「配置转盘」按钮
- 支持奖项自定义配置：
  - 奖项名称（自定义文本输入）
  - 对应扇形数量（数字输入，决定占比和中奖概率）
  - 扇形背景色（颜色选择器输入）
- 完整操作逻辑：
  - 新增奖项、删除奖项
  - 保存配置（验证输入内容有效性）
  - 取消/关闭按钮
- 配置数据持久化（弹窗内）

### 🎉 中奖弹窗
- 转盘旋转结束后弹出专属中奖提示弹窗
- 大号字体突出显示中奖奖项名称
- 简洁提示文案「恭喜你！获得以下奖励」
- 关闭按钮（或点击空白处关闭）
- 页面背景添加轻微遮罩效果

## 使用方法

1. 直接双击 `roulette.html` 文件在浏览器中打开
2. 页面加载完成后即可看到默认配置的转盘
3. 点击「开始抽奖」按钮开始旋转
4. 点击右上角「配置转盘」按钮自定义奖项

## 操作说明

### 抽奖操作
- 点击「开始抽奖」按钮或按空格键开始旋转
- 转盘旋转5秒后自动停止
- 显示中奖结果并弹出中奖弹窗

### 配置操作
1. 点击右上角「配置转盘」按钮打开配置弹窗
2. 修改奖项配置：
   - 修改奖项名称
   - 调整扇形数量（1-20）
   - 选择扇形颜色
3. 点击「新增奖项」添加新奖项
4. 点击「删除」按钮删除奖项
5. 点击「保存配置」应用更改
6. 点击「取消」或按ESC键关闭弹窗

### 快捷键
- **空格键**: 开始抽奖
- **ESC键**: 关闭弹窗

1. 一等奖（手机）- 1个扇形 - 红色
2. 二等奖（平板）- 2个扇形 - 青色
3. 三等奖（耳机）- 3个扇形 - 黄色
4. 四等奖（U盘）- 4个扇形 - 绿色
5. 五等奖（鼠标）- 5个扇形 - 蓝色
6. 谢谢参与 - 5个扇形 - 灰色

## 开发说明

所有代码都包含在单个HTML文件中，便于部署和使用。代码采用模块化设计，主要功能模块包括：

1. **转盘渲染模块** (`renderWheel()`): 根据配置动态生成扇形
2. **旋转逻辑模块** (`startSpin()`): 处理转盘旋转和结果判定
3. **配置管理模块**: 处理奖项配置的增删改查
4. **弹窗管理模块**: 管理配置弹窗和中奖弹窗
5. **事件处理模块** (`bindEvents()`): 统一管理事件监听

## 注意事项

- 扇形数量总和不能为0
- 奖项名称不能为空
- 每个奖项的扇形数量限制为1-20
- 至少需要保留一个奖项
