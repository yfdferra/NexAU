# 科技感数据流程可视化 - 2.5D等距视角

一个基于Three.js构建的科技感数据流程可视化界面，展现从"数据上链→数据归集→数据治理→数据应用→数据归档"的完整链路。

## 功能特性

### 🎨 视觉设计
- **深蓝色渐变背景**：深邃的科技蓝为主色调，搭配亮蓝色、紫色渐变
- **2.5D等距视角**：独特的等距视角展现数据流程
- **科技感元素**：发光效果、科技感描边、网格纹理背景
- **动态连接线**：黄色荧光流动线条展示数据流向

### 📊 数据流程节点
1. **数据上链** - 左侧高楼建筑 + 悬浮立方体模块
2. **数据归集** - 数据接收塔 + 天线系统
3. **数据治理** - 上方服务器集群模块
4. **数据应用** - 中间悬浮立方体 + 方形建筑
5. **数据归档** - 右侧机器人形象

### 🚀 交互功能
- **视角控制**：鼠标拖拽旋转，滚轮缩放
- **键盘控制**：WASD移动，QE升降，方向键旋转
- **聚焦功能**：点击步骤或标注自动聚焦到对应模块
- **动画控制**：可暂停/播放所有动画效果
- **性能监控**：实时FPS显示和性能提示

### 📈 数据展示
- 实时数据统计面板
- 增长趋势可视化
- 系统状态监控
- 性能指标展示

## 自定义配置

### 修改颜色主题
在 `script.js` 中修改 `COLORS` 对象：
```javascript
const COLORS = {
    primaryBlue: new THREE.Color(0x0066ff),
    secondaryBlue: new THREE.Color(0x0044cc),
    // ... 其他颜色
};
```

### 调整数据
在 `script.js` 的 `createLabels()` 函数中修改标注数据：
```javascript
const labels = [
    {
        id: 'data-upload-label',
        title: '数据上链',
        value: '466.23',
        change: '+13.32%',
        // ... 其他配置
    },
    // ... 其他标注
];
```

### 添加新模块
在 `createDataFlowElements()` 函数中添加新的3D元素创建函数。

## 开发说明

### 项目结构
- `init()` - 初始化Three.js场景
- `createDataFlowElements()` - 创建所有3D元素
- `createDataConnections()` - 创建数据连接线
- `createLabels()` - 创建数据标注
- `animate()` - 主动画循环
- `updateAnimations()` - 更新所有动画效果
